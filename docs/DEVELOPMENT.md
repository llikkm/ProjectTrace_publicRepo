# 开发环境与 IMU 示例

## 环境

- Arduino IDE 2.x。
- Espressif `esp32` 开发板包。整理时在本机发现 `3.3.12` 目录；未验证该目录的完整性或本草图的编译兼容性。
- ESP32-S3 开发板；具体板型、Flash 和 PSRAM 参数按实际硬件设置。
- LSM6DS3TR-C 模块。

示例使用开发板包提供的 `Wire` 和串口 API，无需额外安装 IMU 库。Arduino IDE 与开发板包在项目目录之外安装。

## 代码中的接线约定

| ESP32-S3 | IMU 模块 |
| --- | --- |
| 3V3 | 模块兼容的 3.3 V 电源输入 |
| GND | GND |
| GPIO8 | SDA |
| GPIO9 | SCL |

先断电核对模块引脚标识和原理图。代码使用 I²C 地址 `0x6A`，模块的地址选择应与之匹配；I²C 模式的 CS 电平按模块说明设置。

## 运行与输出

1. 打开 `IMU_Test_261104/IMU_Test_261104.ino`。
2. 在 Arduino IDE 选择对应 ESP32-S3 开发板和串口，先编译，再由操作者上传。
3. 打开串口监视器，波特率设为 `115200`。USB CDC 选项按开发板使用的 USB 接口和串口方式设置。
4. 正常初始化时，程序打印 `WHO_AM_I = 0x6A` 和 `IMU initialized!`。
5. 输出中的 `AX/AY/AZ` 单位为 g，`GX/GY/GZ` 单位为 °/s。

代码配置加速度计量程 ±2 g、陀螺仪量程 ±250 °/s，两者输出数据率均为 104 Hz。循环每次读取后等待 50 ms，因此串口输出节奏约为 20 Hz。

本次整理没有连接或刷写硬件，也没有运行编译验证。后续验证时请记录所选开发板、开发板包版本和实测结果。
